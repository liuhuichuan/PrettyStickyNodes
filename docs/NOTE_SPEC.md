# Note 长内容备忘 PRD

关联：[主 PRD](PRODUCT_SPEC.md) · [Figma 第 9 页完整状态板](https://www.figma.com/design/C4suWALokYjH30lU1UFgTr/Untitled?node-id=94-251) · [Figma 第 8 页](https://www.figma.com/design/C4suWALokYjH30lU1UFgTr/Untitled?node-id=91-174) · [Note 状态板源文件](../draft-assets/task-note-states.svg)

## 1. 结论与设计依据

Note 不随正文无限撑大窗口。采用“摘要有限增高，全文固定视口滚动”：列表中快速辨认备忘，进入详情后阅读或编辑完整内容。窗口仅随用户主动调整尺寸而变化，粘贴或输入长文不改变窗口位置和大小。

已有 Figma 第 8 页展示摘要、添加类型选择和基础编辑；Figma 第 9 页 `Note 长内容状态板` 补齐全文阅读、滚动到底部、编辑正文滚动、预览、未保存确认、保存失败和草稿恢复。本 PRD 补充这些行为及尺寸规则，作为开发默认规格。以下数字是新增布局约束，不宣称已在现有图中逐项标注。它取代主 PRD 对纯文本备忘“不实现”的旧限制，并优先于 Task 的 Enter 提交、点击外部保存规则。

## 2. 三个区域的大小规则

尺寸单位为 Windows 逻辑像素（DIP），按系统 DPI 缩放；高度由行高与内边距计算，不能在高字体缩放下硬裁文字。

| 状态 | 高度策略 | 超出后的行为 |
|---|---|---|
| 清单中的单条 Note 摘要 | 标题一行；正文最多两行；垂直内边距各 12，标题行高 20，间距 6，正文行高 18；一行正文约 68，两行约 86 | 摘要末尾省略；点击整条进入全文；摘要内部无滚动条 |
| 清单中的 Notes 分组 | 随备忘条数增长，没有独立固定高度 | Tasks 与 Notes 共用清单滚动区，标题、侧边清单标签、底部 Add 固定；不出现两个并列滚动区 |
| 全文阅读 | 替换清单主体，使用全部可用正文高度 | 正文垂直滚动，返回、Edit 固定可见；不截断全文 |
| Note 编辑 | 正文输入框占剩余可用高度，不按内容自增长 | 输入框内垂直滚动，光标自动保持可见；标题字段、Save、Cancel、Preview 固定可见 |

主面板基准宽 384、高 374 DIP（对应原 400×390 设计画板内的圆角面板）。标题栏约 54；正文左右内边距 20。详情顶部导航行 32、底部操作区 44，正文填满其余空间。编辑态增加标题字段 34 及间距 12，因此默认正文输入区约 150 DIP。不能将设计画板外的说明文字和背景算入窗口。

用户主动拉大窗口时，正文视口扩展，摘要仍最多两行。最小尺寸必须保证在当前字体大小下正文可见至少三行、固定操作不重叠；若系统文字缩放使原高度不足，提高最小窗口高度，禁止遮住 Save。右侧清单标签继续保留且不得被裁剪。

## 3. 列表与全文阅读

- 同一清单先显示 Tasks，再显示 Notes；无内容的分组不显示标题。Note 无完成控件，不参与 Task 拖动排序；默认按创建时间从新到旧显示，编辑不改变位置。
- 两条长备忘分别显示两个摘要；不会因任意一条正文变长而把其他条目推离很远。超过清单可视区域时整个清单滚动。
- 摘要为去除 Markdown 标记后的纯文本，合并换行为空格；未提供标题显示 `Untitled note`。正文为空但有标题时显示 `No content`。
- 单击摘要进入阅读态，正文使用基础 Markdown 渲染；标题栏仍显示所属清单名称，Note 标题在正文顶部显示，避免归属混淆。
- 阅读态有 `Back to list` 和 `Edit`；返回恢复清单滚动位置。默认只在当前窗口中显示一条 Note 的全文，不同时展开多条。
- 正文段落、长链接、长词自动换行；代码块保留空白并独立横向滚动，不能让整个窗口横向滚动。
- 关闭与重新显示窗口保留当前会话位置；重启恢复活动清单的列表态。阅读/编辑切换保持各自滚动位置，首次进入从顶部开始。

## 4. 新增、编辑和预览

1. 清单底部 `+ Add` 展开 Task / Note 选择菜单；菜单浮在现有内容之上，不清空清单。Esc 收起。
2. 选择 Note 后进入空编辑态，包含标题字段和多行正文；新草稿绑定来源清单 ID。
3. Enter 在正文中换行；Ctrl+Enter 或 Save 提交。IME 候选确认不触发保存。点击正文外不自动保存。
4. Cancel 或编辑态 Esc 放弃本次修改；有未保存修改时询问 Save / Discard / Cancel。Save 成功回阅读态，新建取消返回列表。
5. Preview 显示当前草稿的渲染结果，不等于保存；提供 `Back to edit`、Save 和 Cancel，保留输入和光标。Preview 仅是该 Note 的局部视图，不切换整个清单模式。
6. 标题和正文全为空时不能保存，显示 `Add a title or some text`；标题为空、正文非空时保存并显示 Untitled note。标题最多 80 个 Unicode 码点，正文最多 50,000 个；超限保留草稿、明确报错，禁止静默截断或覆盖原文。
7. 正文保存原始换行和 Markdown 文本；不 trim 正文缩进。仅标题去首尾空白；正文是否为空采用空白判断。
8. 编辑/预览草稿时返回列表、切换清单、关闭窗口或主动退出，若有修改，执行 Save / Discard / Cancel；Save 总是写回原清单，失败时保留编辑态并报错，不能继续导航冒充成功。
9. 草稿输入停止 500 ms 后保存独立恢复副本，正常提交或显式丢弃时清除；异常重启后提供 Resume draft / Discard。恢复副本不替换已保存正文，也不保证突然断电前最后 500 ms 的输入已落盘。
10. 阅读态提供删除入口，删除后返回列表并显示 `Note deleted / Undo`，5 秒内可恢复全文及原位置。复用所属清单的撤销槽；新一次 Task/Note 删除或 Task 完成替换上一次撤销。

## 5. 渲染、存储与清单隔离

- 基础 Markdown：段落、标题、粗体/斜体、无序/有序列表、引用、行内代码、围栏代码块、HTTP(S) 链接。不支持的语法按文本显示。
- 原始 HTML 不执行；禁用脚本、内嵌网页及危险链接协议。远程图片不自动加载；图片语法显示替代文字。普通链接由用户点击后交给系统浏览器打开。
- 本阶段只提供基础预览，不提供富文本工具栏、附件、实时双栏预览、Note 转 Task 或全局 Markdown 模式。
- TodoList 新增 `notes: Note[]`；`Note={id, title, bodyMarkdown, createdAt, updatedAt}`。Note ID 稳定；归属由所在清单决定，不增加 completed 或 Task order 字段。
- AppState schemaVersion 升至 3；旧清单 notes 缺失时初始化为空，旧 Todo 不转换。迁移原子写入并保留备份，重复迁移不重复创建数据。
- 草稿独立存储 `{listId, noteId?, title, bodyMarkdown, updatedAt}`；恢复时验证目标清单存在且未归档，异常归属不静默写入 Daily。
- 清单归档/恢复携带 Note；当前清单有编辑草稿时先处理未保存修改。Task 排序不改变 Note 顺序。点击 Save 持久化失败保留草稿，不显示成功。

## 6. 测试与验收

| ID | 操作或输入 | 必须满足的结果 |
|---|---|---|
| NOTE-01 | 同清单添加两条各 2,000 字的 Note | 每条摘要最多两行；窗口大小不变；分别打开能滚到全文末尾 |
| NOTE-02 | 正文从一行变两行再变 100 行 | 摘要只在允许范围增高；超过两行省略，无内部滚动条 |
| NOTE-03 | 20 个 Task、20 个 Note | 只有一个清单纵向滚动区；Add、标题、侧边标签固定 |
| NOTE-04 | 阅读长文，返回列表后再打开 | 返回原列表滚动位置；当前会话阅读位置恢复；全文无截断 |
| NOTE-05 | Enter、Ctrl+Enter、中文输入法候选确认 | Enter 换行，Ctrl+Enter 保存，候选确认不提交 |
| NOTE-06 | 编辑后预览、返回编辑、取消 | 预览反映草稿但不提交；原文与光标保留；明确丢弃后旧正文不变 |
| NOTE-07 | 编辑未保存时切换清单/关闭/退出 | 三选项分别执行；保存写回源清单；取消保持原编辑态 |
| NOTE-08 | 空白、仅标题、仅正文、80/81 字标题、50,000/50,001 字正文 | 边界按规则处理；正文缩进和换行保留；超限不静默截断 |
| NOTE-09 | Markdown、长链接、代码块、HTML/script、图片语法 | 基础渲染正确；代码横滚局限于代码块；不执行脚本或自动请求图片 |
| NOTE-10 | 新建、编辑、删除撤销、重启、清单归档恢复 | 内容和归属无损；删除撤销窗口正确，不影响其他清单 |
| NOTE-11 | 粘贴长文，保存失败或异常退出 | 草稿保留、错误可见；重启能恢复已落盘草稿，不覆盖旧正式内容 |
| NOTE-12 | 100%/125%/150% DPI 与系统文字放大；调整窗口大小 | 正文视口伸缩；标题和操作可见；标签无裁切，摘要不重叠 |
| NOTE-13 | 从 schemaVersion=2 升级并重复启动 | 各清单新增空 notes；旧任务、排序和归档状态不变 |
| NOTE-14 | 键盘访问摘要、阅读、编辑、预览、返回、删除 | 全流程可聚焦，焦点可见；返回后焦点回到原摘要 |

验收示例数据应包含两条长中文备忘、Markdown 标题与列表、超过视口的代码块和长 URL。人工验证阅读末尾并对照原文；自动化验证存储内容全量一致。
